# Boolean Logic Based Loan Pre-Screening Demo

## 📌 Project Overview

The **Boolean Logic Based Loan Pre-Screening Demo** is a web-based software prototype that demonstrates how Boolean logic can be applied to a real-world loan pre-screening scenario.

The project is developed as an educational demonstration of **Digital Logic** concepts.

The system uses four Boolean conditions:

- Stable Income
- Acceptable Credit
- Stable Employment
- Low Debt Burden

Each condition is represented using a Boolean value:

- `1` → Condition is satisfied
- `0` → Condition is not satisfied

The final decision is calculated using the Boolean expression:

**F = I · C · E · D**

where `·` represents the AND operation.

The applicant receives:

- **PRE-SCREEN PASS** when all four conditions are satisfied.
- **HOLD / REVIEW** when one or more conditions are not satisfied.

---

## 🎯 Objectives

The main objectives of this project are:

1. To demonstrate Boolean logic using a real-world scenario.
2. To convert loan pre-screening conditions into Boolean inputs.
3. To implement an AND-based Boolean decision rule.
4. To provide an interactive web interface.
5. To generate and display a complete truth table.
6. To demonstrate normal and edge/fault test cases.
7. To provide explanations for the generated decisions.
8. To deploy the prototype using GitHub Pages.
